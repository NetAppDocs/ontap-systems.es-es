= Devuelve el soporte de arranque AFF A900 defectuoso a NetApp después del proceso de recuperación de arranque manual
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Si un componente de su sistema AFF A900 falla, devuelva la pieza defectuosa a NetApp. Consulte la  https://mysupport.netapp.com/site/info/rma["Devolución de piezas y sustituciones"] página para más información.

Devuelva la pieza que ha fallado a NetApp, como se describe en las instrucciones de RMA que se suministran con el kit. Consulte https://mysupport.netapp.com/site/info/rma["Devolución de piezas y sustituciones"] la página para obtener más información.
