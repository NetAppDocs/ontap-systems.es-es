= Devuelve el soporte de arranque AFF C250 defectuoso a NetApp después del proceso automático de recuperación del arranque
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Una vez que reemplaces el soporte de arranque en un sistema AFF C250, devuelve la pieza defectuosa a NetApp, como se indica en las instrucciones de RMA incluidas con el kit. Consulta la página https://mysupport.netapp.com/site/info/rma["Devolución de piezas y sustituciones"] para más información.
