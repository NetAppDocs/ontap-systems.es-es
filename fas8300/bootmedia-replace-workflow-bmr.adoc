= Flujo de trabajo para la sustitución del medio de arranque en FAS8300 y FAS8700 usando el proceso automatizado de recuperación de arranque
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Empieza a sustituir el soporte de arranque de tu sistema de almacenamiento FAS8300 o FAS8700 mediante el proceso automatizado de recuperación del arranque. El sistema identifica y selecciona automáticamente la opción adecuada del menú de arranque y luego utiliza la imagen de arranque del nodo asociado para reinstalar ONTAP en el soporte de arranque de recambio. Para completar la sustitución, revisa los requisitos, apaga el controlador, sustituye el soporte de arranque, deja que el sistema restaure la imagen y verifica el funcionamiento del sistema.

El proceso de recuperación automática del medio de arranque solo es compatible con ONTAP 9.17.1 y versiones posteriores. Si su sistema de almacenamiento ejecuta una versión anterior de ONTAP, utilice el link:bootmedia-replace-workflow.html["procedimiento de recuperación de arranque manual"] .

Para comenzar, revise los requisitos de reemplazo, apague el controlador, reemplace el medio de arranque, permita que el sistema restaure la imagen y verifique la funcionalidad del sistema.
