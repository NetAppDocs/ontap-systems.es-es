= Infórmate sobre cómo añadir y sustituir módulos de E/S en un sistema AFF A20, AFF A30 o AFF A50
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Los sistemas de almacenamiento AFF A20, AFF A30 y AFF A50 ofrecen flexibilidad a la hora de ampliar o sustituir módulos de E/S para mejorar la conectividad de red y el rendimiento. Añadir un módulo de E/S es fundamental a la hora de actualizar las capacidades de red. El intercambio en caliente o la sustitución de un módulo de E/S es fundamental cuando hay que resolver el fallo de un módulo.

* link:io-module-add.html["Agregue un módulo de E/S."]
+
Puedes agregar módulos de E/S para mejorar la redundancia, ayudando a asegurar que el sistema de almacenamiento permanezca operativo incluso si falla un módulo de E/S. Puedes agregar módulos de E/S cuando hay ranuras disponibles o cuando todas las ranuras están completamente ocupadas.

* link:io-module-hotswap.html["Intercambia en caliente un módulo de E/S"]
+
Puedes realizar un intercambio en caliente de determinados módulos de E/S por otros equivalentes para restablecer el estado óptimo de funcionamiento del sistema de almacenamiento. No necesitas realizar una toma de control manual para hacer el intercambio en caliente del módulo.

+
Para usar este procedimiento, tu sistema de almacenamiento debe estar ejecutando ONTAP 9.17.1 o una versión posterior y cumplir requisitos específicos para la versión de ONTAP que esté ejecutando tu sistema.

* link:io-module-replace.html["Sustituya un módulo de E/S."]
+
Puedes sustituir un módulo de E/S averiado para restaurar el sistema de almacenamiento a su estado de funcionamiento óptimo. Este procedimiento requiere una toma de control manual del controlador con el módulo de E/S averiado.
