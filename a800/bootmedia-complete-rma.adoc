= Devuelve el soporte de arranque AFF A800 defectuoso a NetApp después del proceso de recuperación de arranque manual
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Una vez completado el proceso de recuperación manual del arranque para un soporte de arranque defectuoso en tu sistema AFF A800, devuelve la pieza defectuosa a NetApp. Consulta la  https://mysupport.netapp.com/site/info/rma["Devolución de piezas y sustituciones"] página para más detalles.
