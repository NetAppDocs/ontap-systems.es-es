= Devuelve el soporte de arranque del FAS2700 defectuoso a NetApp
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Después de que reemplaces el soporte de arranque en tu sistema FAS2700, devuelve la pieza con error a NetApp, como se describe en las instrucciones de RMA incluidas con el kit.

Consulta la  https://mysupport.netapp.com/site/info/rma["Devolución de piezas y sustituciones"] página para obtener más información. El sistema FAS2700 solo admite procedimientos manuales de recuperación de medios de arranque. La recuperación automática de medios de arranque no es compatible.
