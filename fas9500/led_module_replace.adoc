= Sustituye el módulo LED USB de tu sistema FAS9500
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
El módulo LED USB de tu sistema FAS9500 proporciona conectividad a los puertos de consola y al estado del sistema. Reemplazarlo no requiere herramientas y no interrumpe el servicio.



[[step-1-replace-the-led-usb-module]]
== Paso 1: Sustituya el módulo USB LED

.Pasos
. Extraiga el módulo USB LED antiguo:
+
.Animación: Extracción/instalación del módulo LED-USB
video::bc46a3e8-6541-444e-973b-ae78004bf153[panopto]
+
image::../media/drw_9500_remove_replace_LED_mod.svg[Reemplace el módulo LED]

+
[cols="20%,80%"]
|===


 a| 
image::../media/icon_round_1.png[Número de llamada 1]
 a| 
Botón de bloqueo



 a| 
image::../media/icon_round_2.png[Número de llamada 2]
 a| 
Módulo LED USB

|===
+
.. Con el bisel retirado, localice el módulo USB LED en la parte frontal del chasis, en la parte inferior izquierda.
.. Deslice el pestillo para expulsar parcialmente el módulo.
.. Tire del módulo para extraerlo del compartimento y desconectarlo del plano medio. No deje la ranura vacía.


. Instale el nuevo módulo USB LED:
+
.. Alinea el módulo con la bahía de manera que la muesca de la esquina del módulo quede situada cerca del pestillo deslizante del chasis. La bahía impide que se instale el módulo al revés.
.. Empuje el módulo dentro del compartimento hasta que esté completamente asentado al ras con el chasis.
+
El módulo emite un clic audible cuando queda bien fijado y conectado al plano central.







[[step-2-return-the-failed-component]]
== Paso 2: Devuelve el componente que ha fallado

. Devuelva la pieza que ha fallado a NetApp, como se describe en las instrucciones de RMA que se suministran con el kit. Consulte https://mysupport.netapp.com/site/info/rma["Devolución de piezas y sustituciones"^] la página para obtener más información.
