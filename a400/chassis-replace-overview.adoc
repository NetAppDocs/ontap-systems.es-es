= Flujo de trabajo para la sustitución del chasis del AFF A400
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Empieza a sustituir el chasis de tu sistema AFF A400 apagando los controladores, trasladando el hardware al chasis de reemplazo y completando la restauración del sistema.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Uno"]link:chassis-replace-shutdown.html["Apague las controladoras"]
[role="quick-margin-para"]
Apague los controladores para realizar el mantenimiento del chasis de forma segura.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Dos"]link:chassis-replace-move-hardware.html["Sustituya el chasis"]
[role="quick-margin-para"]
Traslada los ventiladores, las unidades de disco y los módulos controladores del chasis averiado al chasis de recambio.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Tres"]link:chassis-replace-complete-system-restore-rma.html["Complete el reemplazo del chasis"]
[role="quick-margin-para"]
Finaliza la sustitución comprobando el estado de alta disponibilidad (HA), volviendo a conmutar los agregados si es necesario y devolviendo el chasis averiado a NetApp.
