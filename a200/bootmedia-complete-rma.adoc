= Devuelve el soporte de arranque AFF A200 defectuoso a NetApp
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Devuelve el soporte de arranque AFF A200 defectuoso a NetApp tras haberlo sustituido, tal y como se describe en las instrucciones de RMA incluidas con el kit. Consulta la  https://mysupport.netapp.com/site/info/rma["Devolución de piezas y sustituciones"] página para obtener más información.
